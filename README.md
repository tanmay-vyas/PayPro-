PayPro 💰 Salary Breakdown Tool
PayPro is a simple Python & Streamlit app that lets employees see a detailed breakdown of their salary.
It calculates basic pay, HRA, bonus, transport, taxes, and net salary based on package and attendance, and allows you to download a PDF pay slip for reference.

🧠 Features
Enter your salary package, working days, and present/absent days
Get a detailed salary breakdown
Download salary slip as PDF

📁 Repository Structure
PayPro/
├── main.py
├── requirements.txt
├── static/
├── .streamlit/
└── README.md

🚀 Running the App
streamlit run main.py
Input salary info → view breakdown → download PDF
